# Тех Задание v1.0 — сегментация немецкого предложения по данным Stanza

## 1. Данные
Единственный источник — выход Stanza (depparse + constituency) для предложения: `id, text, lemma, upos, xpos, feats, head, deprel, is_mwt`, дерево `(NP)(PP)(VP)(CNP)`. Никаких внешних знаний, оценочных и семантических суждений. Всё правило формулируется только над этими полями.

## 2. Счёт слов
`lex_count(блока)` = число токенов с `upos ≠ PUNCT`; MWT (`is_mwt=true`, children>1) = 1; длина блока в символах — справочная величина, не участвует в выборе разбиения.

## 3. Атомарные единицы
`unit(w) = [min_leaf(w), max_leaf(w)]` для каждого прямого зависимого root, плюс интервал самого root; список упорядочен по `start_id`. MWT — неделимая единица.

## 4. Запрет реза (NO-CUT) — рёбра, которые не разрываются
| deprel / признак Stanza | что запрещено |
|---|---|
| `det, det:poss, amod, nummod, compound, flat, appos` → NOUN | рез между словом и его head-NOUN |
| `case` + `pobj/obl` | рез внутри PP (ADP ↔ NOUN) |
| `cc` / `conj` с `xpos=TRUNC` | рез внутри конъюнктной цепочки |
| MWT children | рез между частями |
| `aux, aux:pass` + инфинитив/причастие той же леммы глагола | рез внутри глагольной рамки |
| пара ADV/PART→ADV (лемматическая коррелятива) | рез между членами пары |

## 5. Легальные резы (SEAMS)
- **C1** — граница соседних unit по `start_id`.
- **C2** — перед любым токеном `deprel == cc`.
- **C3** — перед первым словом цепочки `case/nmod/appos` при head-NOUN, если слева и справа ≥3 лексических слов.
- **C4** — сразу после конечного глагола root (`xpos ∈ {VAFIN, VVFIN}`), если следующий токен имеет `deprel ∈ {advmod, cc}` и `lemma` ∈ коррелятивного/соединительного набора.

Каждый класс seam хранится со статусом **verified / untested**; verified-классы зафиксированы и не удаляются без данных.

## 6. Пунктуация (PUNCT-glue)
- **P1**: терминальные `.`/`?`/`!` — к блоку, содержащему root.
- **P2**: все прочие знаки (`-`, `,`, скобки) — к **предшествующему** блоку; рез непосредственно перед ними запрещён независимо от `head`.

## 7. Ограничения блока
`min = 3` лексических слов — жёстко: блок <3 → слияние (приоритет: токен, чей head = root, к блоку своего head). `pref = [3,5]`. `cap = 7`: блок 6–7 слов допустим только как объединение целых unit. Блок >7 — вариант снимается.

## 8. Перебор и отбор (детерминированный)
1. Собрать seam-множество: C1∪C2∪C3∪C4 минус NO-CUT minus P2.
2. Перечислить все разбиения по seams; применить P1/P2 и min-слияние; снять варианты с NO-CUT, cap>7, <3.
3. Ранжирование только по структурным признакам Stanza: (a) число блоков вне `pref`, (b) число обязательных min-слияний, (c) число unit, сохранённых целиком, (d) лексикографически — позиции seams слева направо.
4. Все валидные варианты выдаются списком; ранг 1 — формально лучший; остальные — admissible. Если человек выбирает вариант ниже ранга, это **дельта-кейс**: правило уточняется новым verified-seam/приоритетом, человек = ground truth.

## 9. Выход
```json
{"language":"de","rule_version":"vN",
 "recommended":[{"n":1,"text":"","lex_words":3,"toks":[1,2,3],"seams":["C1"]}, ...],
 "admissible":[...],
 "rejected":[{"variant":"","violations":["NO-CUT: det(4)->NOUN(5)"]}],
 "seam_classes_status":{"C1":"verified","C2":"verified","C3":"verified","C4":"verified"}}
```
