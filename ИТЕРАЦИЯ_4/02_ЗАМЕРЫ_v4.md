## 3. Главный замер: формулировка Q3 (S1, остальное одинаково)

| Q3 | F1 на 52 | F1 на 51 | exact 52 | exact 51 |
|---|---|---|---|---|
| **широкая** (как было) | 0.742 | 0.648 | 26/52 | 2/51 |
| **узкая** (предлагаю) | **0.777** | **0.684** | 27/52 | 3/51 |

Разница между «узкой» и «выключенной» — в пределах шума; узкая оставляет защиту от

## 11. Как воспроизвести

```bash
# 1) собрать наборы из ваших markdown-файлов (+ проверка «блоки = предложение»)
python bench/build_sets_v3.py

# 2) кэш разборов (один раз, ~30 с)
python bench/pcache.py   # используется всеми скриптами ниже автоматически

# 3) аудит разметки (какие запреты она нарушает)
python bench/audit_v3.py

# 4) все замеры этой итерации
python bench/exp_v3.py --stage all
#    отдельные стадии: constraints | punct | cap | q22 | pen | grid | final | tune2
#    другой алгоритм:   --algo S4 | S11

# 5) нарезчик (программа) — те же цифры, что на стенде
python MCP-stanza-german-RULE/reference/segment_v3.py --text "Ich habe bei der Firma gearbeitet."
python MCP-stanza-german-RULE/reference/segment_v3.py --file bench/page_demo.txt
python MCP-stanza-german-RULE/reference/segment_v3.py --set bench/sets/heldout_51.jsonl

# 6) валидатор на вашей разметке
python MCP-stanza-german-RULE/reference/validator_v3.py --set bench/sets/corpus52_v3.jsonl
python MCP-stanza-german-RULE/reference/validator_v3.py --set bench/sets/heldout_51.jsonl

# 7) одна фраза, только проверка
python MCP-stanza-german-RULE/reference/validator_v3.py \
   --text "Ich habe bei der Firma gearbeitet." --blocks "Ich habe|bei der Firma gearbeitet."
```

## 12. Программа против стенда (контроль)

`segment_v3.py` (то, что пойдёт в работу) и `exp_v3.py` (стенд) — разные файлы, но цифры
обязаны совпадать. Совпадают:

| набор | стенд (exp_v3) | программа (segment_v3) |
|---|---|---|
| 52 | 0.777, exact 27/52 | 0.777, exact 27/52 |
| 51 | 0.684, exact 3/51 | 0.686, exact 3/51 |

Расхождение на 51 (0.002) — исправленный список открывающих кавычек (`„ » « ‚` вместо
`„ « “`): программа перестала считать закрывающую кавычку «открывающей». Скорость:
0.31 с на предложение, 0.9 с на страницу из 3 предложений (модель грузится 6 с один раз).
