# Отложенная выборка — инструкция для заказчика

В папке лежит **150 немецких предложений** для честной проверки разбивки на смысловые блоки.

| Файл | Что это |
|---|---|
| `heldout_150.md` | **Рабочий файл**: 150 предложений, под каждым строка `→` для вашего ответа |
| `heldout_150.jsonl` | Те же данные в машинном виде (id, регистр, источник, признаки) — не редактировать |
| `coverage.md` | Из чего состоит выборка: регистры, длины, синтаксические признаки |
| `hard_inputs.md` | Отдельный мини-набор «трудного ввода» (кавычки, двоеточие, даты) — не входит в 150 |
| `build.py` | Скрипт сборки (для воспроизводимости) |
| `check_set.py` | Проверка целостности набора |
| `annotate.py` | Разбор ваших ответов и (по желанию) прогон через текущий валидатор |

## Главное правило

**Эти 150 предложений нельзя использовать при написании правил.** Их смысл — измерить качество на незнакомом материале. Если правило подгонять под них, измерение перестанет что-либо значить.

## Формат файла (с переводами)

Каждый блок выглядит так:

```
**[W01]** 11 слов · признаки: conj, genitive, passive
Aber auch einzelne Wörter des Alltagsvokabulars werden auf diese Weise präsentiert.
Но также отдельные слова бытовой лексики представлены таким образом.
→ Aber auch einzelne Wörter des Alltagsvokabulars werden auf diese Weise präsentiert.
```

1. Первая строка — предложение по-немецки (для чтения).
2. Вторая — **русский перевод** (только чтобы понять смысл; размечать его не нужно).
3. Третья (после `→`) — **то же немецкое предложение**: в нём вы и ставите ` / `.

## Как размечать (4 шага)

1. Откройте `heldout_150.md` в любом редакторе (Notepad, Word, VS Code — не важно).
2. Читайте **немецкое** предложение вслух (перевод — подсказка).
3. В строке `→` поставьте ` / ` там, где делаете паузу для вдоха или смыслового ударения.
4. Особые случаи:
   - пауза не нужна (один блок) — поставьте `=` в начале строки `→` и больше ничего;
   - ещё не размечали — оставьте строку `→` как есть (считается незаполненной).

## Правила разметки

- **Косая черта внутри слова — не граница.** «CDU/CSU», «90/Die», «und/oder» оставляйте как есть; граница — только ` / ` (с пробелами).
- **Не исправляйте** текст: ни порядок слов, ни орфографию, ни кавычки, ни опечатки. Мы оцениваем реальный текст, а не причёсанный.
- **Не смотрите в текущее правило** (`RULE.md`, `config.json`) — размечайте на слух. Иначе вы воспроизведёте правило, а не своё восприятие.
- Сомнительное место — поставьте ` /? ` (слэш со знаком вопроса). Это значит «пауза возможна, но я не уверен».
- Одно предложение может быть одним блоком (без `/`) — это нормально.
- Если предложение кажется вам бессмысленным или битым — не правьте, просто поставьте `→ ??` (это тоже данные: значит, текст плохой).

## Сколько это займёт

- 150 предложений ≈ **2–3 часа**.
- Можно частями: по одному разделу (регистру) за раз. Разделы помечены заголовками (`## энциклопедический`, `## новостной`, …).
- Если устали — остановитесь на границе раздела, чтобы не сбиться.

## Что делать потом

1. Сохраните файл (UTF-8, не меняйте расширение).
2. Запустите:

```bash
python heldout/annotate.py heldout/heldout_150.md
```

Скрипт:
- соберёт ваши блоки в `heldout/annotations.jsonl`;
- проверит, что блоки складываются в исходное предложение (и что `CDU/CSU` не разрезано);
- покажет, сколько предложений размечено и где не смог разобрать;
- с флагом `--check` дополнительно прогонит их через текущий судья `rule.py` и покажет, где правило с вами не согласно (это **не** оценка вашей правоты — просто диагностика).

```bash
python heldout/annotate.py heldout/heldout_150.md --check
```

## Зачем именно эти 150

| Регистр | Сколько | Зачем |
|---|---|---|
| энциклопедический (Wikipedia) | 30 | длинные нейтральные предложения, придаточные, причастные обороты |
| новостной (Wikinews) | 21 | официальная лексика, цитаты, даты |
| литературный (Kafka) | 27 | очень длинные предложения, тире, прямая речь, устаревшая орфография |
| инструкция/рецепт (Wikibooks) | 12 | безличные и инфинитивные конструкции |
| юридический (BGB) | 20 | самые длинные и вложенные предложения |
| простая речь (StaGE) | 10 | короткие простые фразы, другая крайность |
| заявление/резюме (вручную) | 20 | **ваш собственный регистр** |
| разговорный/чат (вручную) | 10 | реальные «грязные» тексты |

Длины: S (8–12 слов) — 36, M (13–20) — 54, L (21–35) — 45, XL (36–50) — 15.

Покрытие признаков (см. `coverage.md`): придаточные (subcl) — 36, относительные (relcl) — 20, zu-инфинитив — 20, пассив — 30, сочинение (conj) — 83, генитив — 60, скобки — 12, кавычки — 14, двоеточие — 12, точка с запятой — 6, тире — 8, сокращения — 9, вопросы — 8.

## Черновик ответа

Если удобнее — размечайте в отдельном файле, по одному предложению на строку:

```
W01 Aber auch einzelne Wörter des / Alltagsvokabulars werden auf diese Weise präsentiert.
W02 ...
```

`annotate.py` понимает и такой формат (id + текст с `/`).
