## 1. Делитель предложений: Stanza против SoMaJo

**Зачем:** вы решили (Q12), что за один раз вводится **страница целиком**. Значит кто-то должен
разрезать страницу на предложения. Если он ошибается — все блоки дальше неверны.

**Материал:** 19 кейсов «трудного ввода» (`hard_inputs.md` + даты, ординалы, сокращения, «;», «:»).

| Делитель | Верно | Ошибки |
|---|---|---|
| Stanza `tokenize` | **15/19** | «am 5. Mai» → режет после «5.»; «Zusammenfassend … sagen: Die Jobsuche …» → режет на «:»; «… in Verzug gerät; § 323 BGB …» → режет на «;»; «Ins Geschäft? Ja? Werden …» → склеивает «Ja?» со следующим |
| **SoMaJo** (`de_CMC`, rule-based, GPL-3.0) | **19/19** | — |

**Контрольный замер на чистом материале** (чтобы не создать ложного впечатления):

| Материал | Stanza | SoMaJo |
|---|---|---|
| 150 предложений heldout (каждое — одно предложение) | 150/150 не разбито | 150/150 |
| 52 предложения корпуса | 52/52 | 52/52 |
| 30 «страниц» по 5 предложений | 30/30 | 30/30 |

**Вывод:** на чистом тексте разницы нет; разница — ровно на тех конструкциях, которые есть
в ваших документах (юридические тексты с «§ … ;», даты, двоеточия).

**Важная деталь для внедрения:** SoMaJo нужен **только как делитель предложений**.
Токены и разбор берём у Stanza (иначе ломаются MWT: `im` перестаёт раскладываться на `in+dem`,
и правило `mwt` становится мёртвым — проверено, `exp_integration.py`).
Схема: `страница → SoMaJo (границы предложений) → каждое предложение отдельно в Stanza → разбор`.

Воспроизвести:

```bash
python _exp/exp_sent_split.py     # Stanza
python _exp/exp_somajo.py         # SoMaJo
python _exp/exp_150_split.py      # 202 чистых предложения
python _exp/exp_page_split.py     # 30 «страниц»
python _exp/exp_integration.py    # SoMaJo -> Stanza (MWT!)
```

## 2. Готовые алгоритмы сегментации против наших правил (52 разбивки, 93 реза)

| Метод | Скрипт | exact | P | R | F1 |
|---|---|---|---|---|---|

Что здесь важно:

- `rule.py` **подогнан** на этих 52 предложениях (каждый класс C1–C14 появился из конкретного кейса этого корпуса) — и всё равно F1 0.20.
- Готовые алгоритмы **не знают немецкого** и **не видели** этих разбивок — F1 0.27–0.38.
- Оригинальный subtitle2go без правки формулы даёт 6–7 блоков на предложение: награда за длину в нём не штрафует число сегментов (см. §4.1 основного документа). После замены награды на штраф — 2–3 блока и F1 0.27.

## 4. Проверка инструмента слогов (pyphen, лицензия GPL2+/LGPL2.1+/MPL1.1)

Переносы ≠ слоги. Примеры pyphen на немецком:

| Слово | pyphen | Реально слогов |
|---|---|---|
| Bundesregierung | Bun-des-re-gie-rung (5) | 5 ✅ |
| Arbeitsatmosphäre | Ar-beit-s-at-mo-sphä-re (7) | 6 ❌ (лишнее «s») |
| Testaufgabe | Tes-t-auf-ga-be (5) | 4 ❌ |
| Konstruktionsbüros | Kon-struk-ti-ons-bü-ros (6) | 6 ✅ |
| Geschwindigkeitsbegrenzung | Ge-schwin-dig-keits-be-gren-zung (7) | 8 ❌ |

**Вывод:** для «предохранителя» годится, но с поправками (соединительные «s», «t» на стыке
основ). Точнее — словарь слогов (`mxrn/germanSyllableCount`) или IPA-словарь (`GERpronouncing`).
Для русского/английского та же проблема; поэтому слоги — только мягкий сигнал, не жёсткое правило.
