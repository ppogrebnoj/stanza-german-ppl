## 2. Вклад каждого механизма (S1, 52 предложения, F1)

| Что включено | F1 |
|---|---|
| только «механика» (не перед знаком препинания, не внутри дефисного слова, не после открывающей кавычки) | 0.384 |
| + ваши Q3/Q4 (запреты: не внутри PP, не после служебного слова) | 0.600 |
| + слоговая проверка Q17(г) (7+ слогов → max 3 слова) | 0.600 |
| + штрафы (внутри NP −0.35, перед `ist/hat` −0.25, подлежащее|глагол −0.25) | **0.736** |

То есть:
- **запреты Q3/Q4 — самый большой вклад (+0.22)**;
- **штрафы — ещё +0.14**;
- слоговая проверка **ничего не стоит** (0.000…0.003) — можно включать.

## 3. Что дал «средний» критерий (mean) против суммы

На длинных предложениях сумма поощряет «резать везде» (каждый рез добавляет балл).
Средняя оценка на блок это снимает:

| Алгоритм | sum (лучшая) | mean (лучшая) |
|---|---|---|
| S1 | 0.713 | **0.736** |
| S2 | 0.692 | 0.701 |
| S3 | 0.698 | 0.704 |
| S4 | 0.731 | **0.739** |

Разница небольшая на 52 (короткие предложения), но на 150 (длинные) — принципиальная:
сумма давала 6–7 блоков на предложение вместо 3–4.

## 4. Параметры-победители (сохранены в `bench/results/best_params_v3.json`)

| Параметр | Значение | Смысл |
|---|---|---|
| `ideal` | 3.0 | идеальная длина блока — 3 слова (совпадает с вашей модой) |
| `cap` | 6 | максимум 6 слов (у вас максимум 6) |
| `w_len` | 0.3 | слабый штраф за длину → «лучше лишний рез» (ваше Q5) |
| `objective` | mean | средняя оценка блока |
| `syl_max_words` / `syl_from` | 3 / 7 | слово из 7+ слогов → блок не длиннее 3 слов |
| `pen` | np_inner 0.35, before_aux 0.25, subj_verb 0.25 | мягкие штрафы |

Ограничения: `min_lex=2`, запрет реза после ADP/DET/CCONJ/SCONJ/PART, запрет внутри PP,
запрет перед пунктуацией, внутри дефисного слова, после открывающей кавычки.

## 5. Чего эти цифры НЕ значат

1. **12 предложений — маленькая выборка.** ±0.05–0.10 легко. Финальное слово — за 150.
2. **F1 ≠ «удобно повторять».** F1 0.80 значит «8 из 10 границ совпали с вашими», а не «блоки идеальны».
   Главная мера по вашему решению Q20 — **доля плохих блоков**; её считаем на 150 после разметки.
3. Настройка на 52 (168 блоков) — тоже небольшая; параметры стоит перепроверить, когда
   разметки станет больше (ещё 138 + 8).
4. `exact` низкий (3/12) — это нормально: одна несовпавшая граница из пяти уже «не exact».
